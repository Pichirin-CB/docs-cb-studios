# Contributing to CB Studios Documentation

This is a public-source, proprietary documentation repository. Public visibility does not make the repository open source.

## Before contributing

- Use an issue for documentation errors, broken links, or reproducible website defects.
- Do not submit customer data, license keys, credentials, private webhooks, paid product source code, or protected downloads.
- Do not submit copied text, images, code, or assets unless you own them or have written permission to contribute them.
- Keep public documentation in professional English and follow the structure described in `README.md`.

## Pull requests

Unsolicited pull requests may be closed without review. A submission does not guarantee acceptance.
