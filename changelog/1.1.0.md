<div class="changelog-grid">
  <section class="changelog-section">
    <span class="changelog-section-icon">🔧</span>
    <h2 class="changelog-section-name">Architecture &amp; independence</h2>
    <ul class="changelog-list">
      <li>Removed the <code>hate-bridge</code> dependency.</li>
      <li>Refactored the internal resource structure for easier maintenance.</li>
      <li>Simplified installation across different server environments.</li>
      <li>Introduced extensible integration points through <code>custom.lua</code>.</li>
    </ul>
  </section>

  <section class="changelog-section">
    <span class="changelog-section-icon">📦</span>
    <h2 class="changelog-section-name">Inventory compatibility</h2>
    <ul class="changelog-list">
      <li>Added support for <code>qs_inventory</code>.</li>
      <li>Added support for <code>core_inventory</code>.</li>
      <li>Added support for <code>tgiann-inventory</code>.</li>
      <li>Added client-side and server-side customization hooks for inventory integrations.</li>
    </ul>
  </section>

  <section class="changelog-section">
    <span class="changelog-section-icon">🔔</span>
    <h2 class="changelog-section-name">Notifications &amp; customization</h2>
    <ul class="changelog-list">
      <li>Added hooks for custom notification systems.</li>
      <li>Improved flexibility for server developers.</li>
      <li>Reduced the need to modify internal resource files for custom integrations.</li>
    </ul>
  </section>

  <section class="changelog-section">
